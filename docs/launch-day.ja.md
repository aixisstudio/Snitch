## うまくいったシーケンス

1. **まずコンバージョン**: 多言語 README、綺麗なソーシャルプレビュー、topics、Discussions — 投稿の前に。
2. **ピークは一つ**: HN＋Reddit＋PH を同日に積層; 週間ボリュームより速度が大事。
3. **返信 60 秒以内**: HN の即時著者コメントが差を生んだ。
4. **ローカルはスケールする**: README zh-CN が CN ニュースレター掲載後 ~55 中国人訪問者/日を運んだ。
5. **冷たいオーディエンスは無駄**: X/LinkedIn でフォロワー無しの投稿は無意味 — 既存コミュニティに投資すべき。
