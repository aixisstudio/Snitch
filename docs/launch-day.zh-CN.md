## 奏效的顺序

1. **转化优先**：多语言 README、干净的社交预览、topics、Discussions——先于一切发帖。
2. **单一峰值**：同日叠加 HN + Reddit + PH；速度重要，不是周总量。
3. **60 秒内回复**：HN 上即时的作者评论决定了成败。
4. **本地化可复制放大**：中文 README 经 CN 通讯推荐后带来约 55 名中国访客/天。
5. **冷启动受众无用**：X/LinkedIn 无粉丝发帖无意义——不如投入既有社区。
