# Snitch —— 冲击 GitHub Trending 与 10K ⭐ 的增长战役

[English](growth-campaign.md) | [Français](growth-campaign.md) | [Español](growth-campaign.es.md) | [Deutsch](growth-campaign.de.md) | [Русский](growth-campaign.ru.md) | [日本語](growth-campaign.ja.md) | [Português](growth-campaign.pt-BR.md) | **中文**

> **目标：发布日 24 小时内获 100–300⭐ → 进入 GitHub Trending → 自增长循环。**
> 黄金法则：所有流量必须同日汇聚到仓库。含全部表格的权威版本见 `growth-campaign.md`（EN/FR）。

## 四层策略

```
层 4 —— 长尾（数周）              SEO 文章、常青问答、目录收录
层 3 —— 复用循环                  每次发布 = 新的分享契机
层 2 —— 当日（周二）              PH + HN 重发 + Reddit + 社媒，全部叠加
层 1 —— 转化（常开）              让访客变成 star 的仓库
```

## 层 1 —— 仓库转化

匿名化社交预览图、启用 Discussions + 置顶帖、20/20 topics、FUNDING.yml、8 语言 README + 演示 GIF、克制的 star CTA、awesome 徽章、开头放各 OS 直接下载链接。

## 层 3 —— 复用

- 每次发布 = 发帖理由（v1.x → 每 2-3 周一波）
- Changelog → dev.to/Medium 交叉发布
- 每月「State of Snitch」帖——真实数据透明
