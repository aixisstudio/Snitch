## A sequência que funcionou

1. **Conversão primeiro**: README multilíngue, social preview limpa, topics, Discussions — antes de qualquer post.
2. **Um único pico**: empilhar HN + Reddit + PH no mesmo dia; velocidade importa, não volume semanal.
3. **Respostas <60 s**: o comentário imediato do autor no HN fez a diferença.
4. **O local escala**: o README zh-CN trouxe ~55 visitantes chineses/dia após um post numa newsletter CN.
5. **Nada de audiência fria**: sem seguidores no X/LinkedIn, postar não vale — melhor investir em comunidades existentes.
