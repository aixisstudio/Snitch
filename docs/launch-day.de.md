## Die Sequenz, die funktionierte

1. **Konversion zuerst**: mehrsprachiges README, saubere Social Preview, Topics, Discussions — vor jedem Post.
2. **Ein einziger Peak**: HN + Reddit + PH am selben Tag stapeln; Velocity zählt, nicht Wochenvolumen.
3. **Antworten <60 s**: der sofortige Autorkommentar auf HN machte den Unterschied.
4. **Lokales skaliert**: das README zh-CN brachte ~55 chinesische Besucher/Tag nach einem CN-Newsletter-Post.
5. **Keine kalte Audience**: ohne Follower auf X/LinkedIn bringt Posten nichts — besser in bestehende Communities investieren.
