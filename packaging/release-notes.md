## Download Snitch @TAG@

Pick the file for your system, then follow the two-line install steps below.

| Your system | Download | Install |
|---|---|---|
| **Windows 10/11** | `Snitch-Setup-windows.exe` | Double-click the installer. Windows SmartScreen may warn (the app is not code-signed yet): click **More info -> Run anyway**. |
| **macOS (Apple Silicon)** | `Snitch-macos-arm64.dmg` | Open the `.dmg`, drag Snitch into Applications. On first launch, right-click the app -> **Open** -> **Open** (Gatekeeper warning, app not notarised yet). |
| **Linux, easiest** | `Snitch-x86_64.AppImage` | `chmod +x Snitch-x86_64.AppImage` then double-click or run it. |
| **Linux, Debian/Ubuntu** | `snitch-linux-amd64.deb` | `sudo apt install ./snitch-linux-amd64.deb` |
| **Linux, Snap** | `snitch-linux-amd64.snap` | `sudo snap install --dangerous snitch-linux-amd64.snap` |

Snitch is also on `winget`, `scoop` and `brew` (`brew install --cask aixisstudio/tap/snitch`).

`Snitch-Lite-Setup-windows.exe` is a smaller Windows build with the same core features. The `snitch-backend-*.tar.gz` and `latest*.yml` files are for advanced/headless installs and auto-updates; most people do not need them.

> First launch tip: real packet capture needs administrator/root rights, or run `SNITCH_DEMO=1` to try the app with synthetic traffic.

## Telecharger Snitch @TAG@

Choisissez le fichier correspondant a votre systeme, puis suivez les etapes d'installation ci-dessous.

| Votre systeme | Fichier | Installation |
|---|---|---|
| **Windows 10/11** | `Snitch-Setup-windows.exe` | Double-cliquez sur l'installateur. SmartScreen peut afficher un avertissement (l'application n'est pas encore signee) : cliquez sur **Informations complementaires -> Executer quand meme**. |
| **macOS (Apple Silicon)** | `Snitch-macos-arm64.dmg` | Ouvrez le `.dmg`, glissez Snitch dans Applications. Au premier lancement : clic droit sur l'app -> **Ouvrir** -> **Ouvrir**. |
| **Linux, le plus simple** | `Snitch-x86_64.AppImage` | `chmod +x Snitch-x86_64.AppImage` puis double-cliquez ou lancez-le. |
| **Linux, Debian/Ubuntu** | `snitch-linux-amd64.deb` | `sudo apt install ./snitch-linux-amd64.deb` |
| **Linux, Snap** | `snitch-linux-amd64.snap` | `sudo snap install --dangerous snitch-linux-amd64.snap` |

Snitch est aussi sur `winget`, `scoop` et `brew` (`brew install --cask aixisstudio/tap/snitch`).

`Snitch-Lite-Setup-windows.exe` est une version Windows plus legere avec les memes fonctions principales. Les fichiers `snitch-backend-*.tar.gz` et `latest*.yml` servent aux installations avancees et aux mises a jour automatiques ; la plupart des utilisateurs n'en ont pas besoin.

> Astuce premier lancement : la capture reseau reelle demande les droits administrateur/root, ou lancez `SNITCH_DEMO=1` pour essayer l'application avec un trafic simule.
