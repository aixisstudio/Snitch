## Secuencia que funcionó

1. **Conversión primero**: README multiidioma, social preview limpia, topics, Discussions — antes de cualquier post.
2. **Un solo pico**: apilar HN + Reddit + PH el mismo día; la velocidad cuenta, no el volumen semanal.
3. **Respuestas <60s**: el comentario autor inmediato en HN marcó la diferencia.
4. **Lo local escala**: README zh-CN trajo ~55 visitantes chinos/día tras un post en una newsletter CN.
5. **Nada de audiencia fría**: sin followers en X/LinkedIn, postear no sirve — mejor invertir en comunidades existentes.
