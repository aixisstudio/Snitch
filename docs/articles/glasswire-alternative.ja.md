Windows でネットワークモニターを探したことがあれば、GlassWire にぶつかったはず。洗練されていて見た目も良い — そして paywall が始まる: 履歴はサブスク、ファイアウォール機能はティア制、しつこく提示されるアカウント、クラウド「エリート」同期。

ソフトに金を払うこと自体は悪くない。だが「自分の PC が何に繋がっているか見せて」は基本的な衛生 — 課金ゲートすべきではないとも言える。私は [Snitch](https://github.com/aixisstudio/Snitch) の作者 — 無料のオープンソース（AGPL）代替 — なので、セールストークではなく正直な比較をする。

## Snitch vs GlassWire、機能ごと

| | **Snitch** | **GlassWire** |
|---|---|---|
| 価格 | 永久無料 | Freemium — 主要機能は paywall |
| ライセンス | AGPL オープンソース | プロプライエタリ |
| アカウント | **一切不要** | アカウント/クラウドティア推奨 |
| テレメトリ | **オプトイン無しの外部呼び出しはゼロ**（GeoIP、更新、脅威インテル、Webhook はデフォルト無効） | 同期/機能用の phone-home |
| データの所在 | ローカル SQLite、あなたのもの | クラウド連携機能あり |
| 接続のライブ世界地図 | ✅ オフライン測位 | ✅（有料ティア） |
| アプリ別トラフィック/帯域 | ✅ | ✅（一部無料） |
| 履歴 | 24 時間無料（SQLite リングバッファ） | 無料ティアでは制限あり |
| 異常アラート（ポートスキャン、ビーコニング、流出、DNS トンネル） | ✅ | ✅（ほぼ有料） |
| LAN デバイススキャン | ✅ パッシブ、ARP 経由 | ✅（有料） |
| ファイアウォール/ブロッキング | ✅ OS ファイアウォール連携＋lockdown（best-effort、権限必要） | ✅（GlassWire の方が成熟） |
| 脅威インテル評判 | ✅ オプトイン（AbuseIPDB / OTX / VirusTotal、自分のキー） | ❌ |
| プロセス kill/suspend | ✅ 内蔵 | ✅ |
| フォレンジックエクスポート | ✅ JSON / CSV / STIX | ❌ |
| プラットフォーム | macOS、Windows、Linux | Windows、Android |
| プライバシースコア/トラッカー検出 | ✅ 編集可能リスト | ❌ |

## GlassWire がまだ勝る点

公平に言うと:

- **ブロッキングの成熟度。** GlassWire のアプリケーションファイアウォールは 10 年の洗練がある — Snitch の送信ブロッキング（v1.2 追加）は OS ネイティブファイアウォールを best-effort で連携し、実際のルール適用にはキャプチャ権限が必要。インタラクティブな「このアプリを拒否」プロンプトが本筋なら、GlassWire（または無料の Portmaster）が依然として洗練された選択。
- **完成度。** GlassWire は 10 年の UI 開発がある。Snitch はずっと若い — グラフは素晴らしいが、設定は実用レベル、粗さは覚悟を。
- **長期履歴保持** — Snitch は設計上 24 時間のみ（プライバシーファーストとはトラフィックを溜め込ま*ない*ことでもある）。

## 重要なアーキテクチャの違い

GlassWire のモデルは業界標準: 無料ティア → 苛立ち → サブスク → クラウド機能。Snitch は逆: 実行するバイナリが製品の全部。ロックが無いから解除も無い。履歴はローカル SQLite ファイルに住む — コードは AGPL なので、こっそり phone-home し始めれば diff が公開される。

具体的に: API は loopback でトークン認証、テレメトリエンドポイントゼロ、コード内に分析 SDK は一切無い（grep してみて — オープンソースだから）。

## 試してみる

```bash
# Windows: Npcap をインストール、release の exe を管理者として実行
# Linux/Docker:
docker run --network host ghcr.io/aixisstudio/snitch
# macOS: パッケージ版アプリまたは brew
# 管理者無しのデモモード: SNITCH_DEMO=1
```
