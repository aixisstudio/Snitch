# Snitch — Campaña growth hacia GitHub Trending & 10K ⭐

[English](growth-campaign.md) | [Français](growth-campaign.md) | **Español** | [Deutsch](growth-campaign.de.md) | [Русский](growth-campaign.ru.md) | [日本語](growth-campaign.ja.md) | [Português](growth-campaign.pt-BR.md) | [中文](growth-campaign.zh-CN.md)

> **Objetivo: 100–300⭐ en 24h el día D → entrada en GitHub Trending → bucle autoalimentado.**
> Regla de oro: todo el tráfico debe converger el MISMO día al repo. La versión canónica con tablas completas está en `growth-campaign.md` (EN/FR).

## La estrategia en 4 capas

```
Capa 4 — LARGA COLA (semanas)        artículos SEO, Q&A evergreen, directorios
Capa 3 — BUCLE DE RECURRENCIA        cada release = nuevo momento de compartir
Capa 2 — DÍA D (martes)              PH + repost HN + Reddit + social, todo apilado
Capa 1 — CONVERSIÓN (siempre on)     repo que convierte visitante → star
```

## Capa 1 — Conversión del repo

Social preview anonimizada, Discussions activadas + post fijado, 20/20 topics, FUNDING.yml, README en 8 idiomas + GIF demo, CTA star sutil, badge awesome, links de descarga directa por OS en las primeras líneas.

## Capa 3 — Recurrencia

- Cada release = excusa para postear (v1.x → nueva ola cada 2-3 semanas)
- Changelog → cross-post dev.to/Medium
- Post mensual « State of Snitch » con métricas reales

## Capa 4 — Larga cola

- Artículos SEO de `docs/articles/` (GlassWire/Little Snitch alternatives) en dev.to/Medium
- Respuestas StackExchange/Quora « how to see what my PC connects to »
- Directories: AlternativeTo, SaaSHub, LibHunt, awesome lists
- Comunidades localizadas: Qiita/Zenn (JP), V2EX/Juejin (CN), dev.to ES/PT
