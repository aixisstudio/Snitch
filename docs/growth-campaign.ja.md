## 4 層戦略

```
層 4 — ロングテール（数週間）      SEO 記事、常緑 Q&A、ディレクトリ
層 3 — 再帰ループ                  リリース毎 = 新しいシェアの機会
層 2 — 当日（火曜）                PH + HN 再投稿 + Reddit + SNS 全て積層
層 1 — コンバージョン（常時）      訪問者 → スターへ変換するリポ
```

## 層 1 — リポのコンバージョン

匿名化ソーシャルプレビュー、Discussions 有効＋ピン留め投稿、20/20 topics、FUNDING.yml、8 言語 README＋デモ GIF、控えめな star CTA、awesome バッジ、冒頭に OS 別直接ダウンロードリンク。

## 層 3 — 再帰

- リリース毎 = 投稿の口実（v1.x → 2-3 週毎に新しい波）
- Changelog → dev.to/Medium クロスポスト
- 月次「State of Snitch」投稿 — 実数値の透明性

## 層 4 — ロングテール
