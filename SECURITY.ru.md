## Сообщение об уязвимостях

Сообщайте об уязвимостях приватно через функцию GitHub «Report a
vulnerability» (вкладка Security) или по email мейнтейнерам, указанным в
профиле репозитория. Не открывайте публичные issues по проблемам
безопасности.

## Локальная поверхность атаки

API раскрывает весь ваш граф трафика — он защищён по дизайну:

- **Токен-аутентификация** на каждом REST-endpoint и WebSocket
  (`X-Snitch-Token` или `?token=`). Под Electron генерируется при каждом
  запуске, в остальных режимах сохраняется с правами 0600.
- **Привязка к loopback** (`127.0.0.1`) по умолчанию во всех режимах.
- **Белый список Origin** на handshake WebSocket (loopback-хосты + `null`)
  против перехвата WebSocket cross-site.
- **Ограниченный CORS** — только loopback-origin, без учётных данных.

## Привилегии

Захват пакетов требует повышенных привилегий — но ими обладает только
бэкенд. Упакованное Electron-приложение запускает UI без привилегий на
любой ОС и повышает ТОЛЬКО бэкенд через нативный запрос платформы:

- **Windows:** `Start-Process -Verb RunAs` (один запрос UAC на запуск) + Npcap (вы ставите с npcap.com)
- **macOS:** `osascript … with administrator privileges` (нативный диалог пароля)
- **Linux:** `pkexec` (диалог polkit); без polkit — откат к непривилегированному режиму

Повышенный дочерний процесс останавливается через аутентифицированный
endpoint `/shutdown`, так как непривилегированный процесс не может его
сигнализировать. Отказ от запроса предлагает повторить / продолжить без
захвата вместо жёсткого выхода.

## Зависимости

Scapy удалён (GPL-2.0-only + большая поверхность атаки). Захват — это
минимальный ctypes-биндинг к libpcap плюс собственный ограниченный парсер.
Зависимости закреплены и отслеживаются Dependabot.
