## [1.5.0] — 2026-10-22

### Добавлено

- **Пассивная инспекция TLS-сертификата** — `capture/tlscert.py` собирает сообщение `Certificate` сервера из TCP-сегментов (лимит 16 КиБ/поток) и читает DER листа: издатель/субъект, флаг самоподписи, SAN, срок → `TLS_CERT` при самоподписи или mismatch SAN/SNI. TLS 1.3 честно помечается ненаблюдаемым — без MITM и расшифровки.
- **Эвристика ICMP-туннеля** — повторные объёмные echo-пayloads (≥24 Б, 3+ за 5 мин) → `ICMP_TUNNEL` (сигнатура ptunnel/icmpsh).
- **Детект высокой энтропии** — почти случайные головы payload (≥4,7 бит/байт) на открытых сокетах → `HIGH_ENTROPY` (признак скрытого шифрования/стего).
- **Isolation Forest (чистый Python)** — `detection/iforest.py` + `mlflow.py` скорят исходящие потоки по 6 признакам; `ML_ANOMALY` при score ≥0,62, неактивно до 384 выученных потоков.
- **Ask-on-connect (Linux NFQUEUE, opt-in)** — `ask_enabled` удерживает новые исходящие потоки в очереди 7 до `POST /security/ask/verdict` — настоящий вердикт, таймаут по умолчанию дропает.
- **eBPF egress-эндфорсмент** — `detection/ebpf_enforce.py` + `POST /security/ebpf/isolate|block` — дропы в ядре только для процессов в cgroup snitch.
- **Доказательство hollowing** — `POST /security/hollow` сравнивает исполняемые страницы в RAM с файлом на диске (Linux, `/proc`).
- **Синхронизация IOC с пирами** — `gossip_peers` + `gossip_enabled`: солёные Merkle-пакеты каждые 5 мин явно перечисленным пирам — только хеш-коммитменты, без discovery.
- **Syslog** — `syslog_addr` (UDP или `tcp://`) пересылает алерты warning/critical как RFC 3164 — путь в SIEM/Wazuh.
- **Гео-правила + автоблок** — свои правила с `asn`/`country` (локальная mmdb) и `action:"block"` ставят настоящие правила фаервола на каждый совпавший IP.
- **Действующие алерты + UI настроек** — Блок IP / Убить / Приостановить / Разрешить-Запретить на каждый алерт; новые элементы в настройках (syslog, ask, пиры).
- **Backend nftables + firejail** — `nft` при отсутствии iptables (отдельная таблица `inet snitch`); `firejail --net=none` как фолбэк песочницы.

## [Unreleased]

### Добавлено

- **Оркестрация исходящего фаервола** — пользовательские правила (`ip`, `cidr`, `domain`, `process`, `port`), применяемые к нативному фаерволу ОС на усилиях best-effort: `netsh advfirewall` в Windows, `iptables` в Linux, генерируемый якорь `pf` в macOS. Персистентные, переприменяются при старте, честное `applied=False` без привилегий (матчинг и счётчики `BLOCKED_ATTEMPT` работают).
- **Lockdown** — кнопка паники, режущая исходящий трафик к публичным IP с сохранением loopback/LAN (цепочка `SNITCH_LOCK` в Linux, правила `netsh`, якорь `pf`).
- **Действия над процессами** — `POST /processes/kill` и `POST /processes/suspend` (по PID; отказ для PID ≤ 3 и самого Snitch); кнопки kill/suspend в списке процессов.
- **Threat intelligence (opt-in)** — проверки репутации через AbuseIPDB, AlienVault OTX или VirusTotal с вашим ключом API; по умолчанию выключено, один вызов на новый публичный IP, ограниченный LRU-кэш + дедупликация, тревоги `THREAT_HIT` при подозрительных/вредоносных вердиктах.
- **Внешние вебхуки (opt-in)** — тревоги warning/critical отправляются POST'ом в Discord, Slack, Telegram (с chat ID) или любой endpoint; по умолчанию выключено.
- **Новые детекции** — `DNS_TUNNEL` (слишком длинные DNS-имена/метки), `CLEARTEXT` (исходящие FTP/Telnet/HTTP/открытая почта), `BASELINE_DEVIATION` (обученный профиль стран на процесс, персистентный).
- **Аудит безопасности** — `GET /security/audit` вычисляет счёт 0–100 и рекомендации на человеческом языке из недавних тревог и живого графа; отображается в панели фаервола.
- **Форензик-экспорт** — `GET /forensics/export?format=json|csv|stix` собирает дерево процессов, SHA-256 исполняемого файла, тревоги и историю трафика; STIX — минимальный bundle 2.1 (indicators + observed-data) для импорта в SIEM.
- **UI фаервола и безопасности** — отдельная панель: переключатель lockdown, создание/переключение/удаление правил, счётчики блокировок по правилам, честная поддержка платформ, отчёт аудита, кнопки выгрузки форензики; действие «Заблокировать» по соединению в сайдбаре.
- **Пять новых локалей UI** — de, ru, ja, pt-BR, zh-CN (8 всего, проверена паритетность 280 ключей); словари перенесены в `frontend/src/locales/*.js` — новый язык = PR из одного файла.

## [1.1.0] — 2026-10-22

### Добавлено

- **Автообновление** — десктопное приложение проверяет GitHub Releases при запуске и каждые 6 ч через electron-updater (фиды `latest-*.yml` уже публиковались). Загрузки ставятся при перезапуске; статус в трее и настройках в реальном времени. Отключение в настройках или через `SNITCH_NO_UPDATE=1`.
- **Видимость QUIC / HTTP/3** — потоки UDP/443 помечаются `QUIC/HTTP3` вместо сваливания в HTTPS или «неизвестно». SNI пакета QUIC Initial зашифрован и никогда не читается — метка честно отражает наблюдаемое.
- **Watchlist** — закрепляйте IP или суффиксы доменов (`example.com` также совпадает с `api.example.com`); выделенная тревога `WATCHLIST_HIT` срабатывает при первом контакте, с ограничением по (запись, хост). Персистентно, управляется в настройках.
- **Тревога исходящего объёма на процесс** — `UPLOAD_SPIKE` предупреждает, когда процесс превышает настраиваемый потолок МБ/мин (50 по умолчанию, 0 = выкл.) — покрывает эксфильтрацию, которую относительный `VOLUME_SPIKE` пропускает у свежих процессов.
- **Выбор интерфейса захвата** — `GET/POST /capture/interfaces` + выпадающий список устройств libpcap в настройках; переключение мгновенно перезапускает захват. Заменяет переменную `SNITCH_IFACE` для десктоп-пользователей.
- **Контекст Wi-Fi** — тулбар показывает текущий SSID (или интерфейс захвата вне Wi-Fi). Best-effort по ОС, кэш 60 с.
- **Испанская локаль UI** — полный словарь `es` (194 ключа, паритет проверен); переключатель становится EN/FR/ES.
- **Snap-пакет** — electron-builder теперь выпускает `.snap` в strict confinement (с plug `network-observe` для захвата AF_PACKET). Flatpak сознательно не выпускается — песочница не может открыть сырой захват (задокументировано в `docs/PACKAGING.md`).
- **Бесплатный путь подписи кода** — опциональная интеграция SignPath Foundation OSS в CI (`vars.SIGNPATH_*` + `secrets.SIGNPATH_API_TOKEN`): установщик Windows подписывается Authenticode автоматически после принятия проекта. Полностью описано в `docs/SIGNING.md`, включая честную ситуацию с macOS (бесплатной нотаризации нет).

## [1.0.8] — 2026-10-22

### Изменено

- **Настоящая нативная светлая тема** — заменяет инвертирующий фильтр v1.0.7 полноценной системой дизайн-токенов: каждая поверхность, текст, рамка и акцент рисуются через CSS-переменные с вручную подобранной светлой палитрой. Карта, граф, таймлайн и WebGL-аврора следуют теме, выбор персистентен.

## [1.0.7] — 2026-10-22

### Добавлено

- **Светлая тема** — из коробки уважает `prefers-color-scheme`, переопределяется кнопкой солнце/луна в тулбаре; выбор сохраняется в `localStorage`. Реализована инверсией с сохранением оттенка тёмной палитры, поэтому графы, карта и аврора остаются согласованными.

### Исправлено

- **Соответствие каталогу AppImage** — Linux-ассет теперь называется `Snitch-x86_64.AppImage` (корректное именование архитектуры), а electron-builder публикует метаданные обновлений GitHub (`latest-linux.yml` + `.zsync`), включая автообновление через инструменты, совместимые с AppImageUpdate.

## [1.0.6] — 2026-10-21

### Добавлено

- **Одна загрузка на ОС** — каждый тег поставляет готовые приложения, собранные CI:
  - **Windows** — `Snitch Setup <версия>.exe` (Electron + NSIS: нативное окно, трей, встроенная проверка Npcap, запрос UAC при запуске бэкенда) и `Snitch-Lite-Setup-<версия>-windows-x64.exe` (Inno Setup: только бэкенд, UI открывается в браузере).
  - **macOS (Apple Silicon)** — `Snitch-<версия>-macos-arm64.zip` + `.dmg`, собранные в CI (раньше вручную).
  - **Linux** — `Snitch-<версия>.AppImage` + `.deb` — Docker больше не обязателен для десктопа.
- **Режим бэкенда `--launcher`** — выбирает свободный loopback-порт, вычисляет API-токен и открывает браузер; используется ярлыком Lite-установщика.

### Исправлено

- **Автономные бэкенд-бандлы теперь содержат UI** — `frontend_dist` упаковывается внутрь PyInstaller-бандла на всех ОС; раньше голый tarball отдавал только API.

### Изменено

- CI-джоб `package` собирает установщики Electron на всех трёх ОС, а `release`-джоб автоматически публикует все артефакты в GitHub release.

## [1.0.5] — 2026-10-17

### Добавлено

- **Поддержка Windows** — упакованное приложение загружается и захватывает в Windows (Npcap).
- **Иконки процессов** — иконки Lucide для каждого процесса в таблице приложений (внешний вклад).

- Падение бэкенда на сборках PyInstaller `console=False` (`sys.stdout`/`sys.stderr` = None) — issue #25.
- Выбор интерфейса захвата в Windows — Snitch теперь выбирает интерфейс с маршрутом по умолчанию вместо `vEthernet (WSL)`.
- `NaNh ago` в метках времени тревог с часовыми смещениями.
- Сплэш Electron больше не прячет диалоги ошибок; сообщение о таймауте перечисляет причины + папку логов.
- Четыре оставшиеся английские строки переведены во французском словаре (внешний вклад).
- Версия теперь из единого источника `backend/version.py`.

### Изменено

- React 18 → 19, uvicorn 0.30 → 0.54, fastapi → 0.143, psutil → 7.2, websockets → 17.2, maxminddb → 3.2, aiofiles → 25.1, lucide-react → 1.55, vite → 8.3.4, electron → 44.7 (+ dev deps).
