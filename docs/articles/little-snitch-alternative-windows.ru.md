Твой компьютер общается с сотнями серверов каждый день. Большая часть — нормально: обновления, синхронизация, телеметрия, на которую ты подписался. Часть — нет. Вопрос «с кем на самом деле говорит моя машина?» — причина, по которой Little Snitch 15 лет — базовая программа на macOS.

Проблема: **Little Snitch не существует на Windows и Linux.** А большинство «альтернатив» на Windows либо платные, либо требуют аккаунт, либо firewall-first — когда нужна была только видимость.

Я автор [Snitch](https://github.com/aixisstudio/Snitch) — open-source визуализатора сети реального времени (AGPL) с Windows-портом — так что сразу честно. Вот реальное состояние опций.

## Сначала: визуализатор или блокировщик

Стоит уточнить, потому что их путают:

- **Видимость** = «покажи, с кем говорит машина» (карта, привязка к приложениям, история)
- **Блокировка** = «дай мне решать, что разрешено» (правила фаервола, промпты)

Little Snitch делает и то и другое. Некоторые альтернативы — одно из двух. Snitch теперь тоже делает оба — видимость его сильная сторона, а блокировка оркестрирует фаервол ОС.

## Честное сравнение

|---|---|---|---|---|---|

| **Snitch** | macOS, Windows, Linux | ✅ правила OS-фаервола + lockdown (best-effort) | ✅ AGPL | нет | Живая карта мира, детект аномалий, privacy score, opt-in threat intel, форензик-экспорт. 100% локально. |
| **Portmaster** | Win, Linux, macOS | ✅ | ✅ ядро бесплатно | нет | Блокировка на уровне DNS + правила приложений. Тяжелее — работает системным сервисом. |

| **GlassWire** | Windows, Android | ✅ | freemium | навязывает аккаунт/cloud | Отполированный UI, но ключевые фичи и история за пейволом, и он выпрашивает облачный тариф. |

## Что Snitch реально делает

Одним предложением: **живая карта каждого соединения твоего компьютера — какое приложение, какой сервер, какая страна.**

- Force-граф + карта мира в реальном времени, офлайн-геолокация (MaxMind/DB-IP — IP не покидают машину)
- Атрибуция процессов: какое *приложение* открыло соединение, а не просто IP
- Детект аномалий: port-сканы, паттерны beaconing, объёмы эксфильтрации, DNS-туннелирование
- Privacy score + детект трекеров по редактируемым спискам
- Трафик по приложениям, таймлайн (15/30/60 мин), история SQLite 24 ч
- Пассивный LAN-сканер (читает ARP-таблицу — показывает все устройства сети)
- **Исходящие правила + lockdown**: блок IP/CIDR/домена/процесса/порта в фаерволе ОС (`netsh advfirewall` на Windows), kill/suspend процессов, форензик-экспорт JSON/CSV/STIX
- **Opt-in threat intel**: AbuseIPDB / OTX / VirusTotal с твоим ключом API

То, что важно любителям приватности: **всё локально.** Без аккаунта, без телеметрии, и каждый исходящий вызов — GeoIP, обновления, threat intel, вебхуки — opt-in. API аутентифицирован токеном и по умолчанию привязан к loopback.

## Чего Snitch НЕ делает

Секция честности, потому что HN/Reddit всё равно спросит:

- **Его блокировка — оркестрация, а не драйвер.** С v1.2 Snitch пушит правила `ip`/`cidr`/`domain`/`process`/`port` в нативный фаервол ОС (`netsh advfirewall` на Windows, `iptables` на Linux, `pf` на macOS) плюс lockdown — best-effort: правила требуют тех же привилегий, что и захват, чтобы реально применяться, и `pf` не умеет матчить процессы. UI честно сообщает, если правило не применилось. Для зрелого интерактивного фаервола приложений Portmaster (или Little Snitch на macOS) остаётся эталоном.
- **Нужен admin/root** для захвата (неизбежно — как Wireshark).
- **Глубокая диссекция пакетов** — тут Wireshark всё ещё побеждает. Snitch — вид с высоты 10 000 футов.

## Установка на Windows

1. Установи [Npcap](https://npcap.com) (Windows-драйвер захвата — обязателен, та же зависимость, что у Wireshark)
2. Скачай `Snitch Setup <версия>.exe` с [последнего релиза](https://github.com/aixisstudio/Snitch/releases) — нативное Electron-приложение с треем — или Lite-установщик (только бэкенд)
3. Запусти от имени администратора (установщик сам обработает UAC-промпт при запуске бэкенда)
4. UI откроется сам — в окне Electron или в браузере с Lite

Linux: `docker run --network host ghcr.io/aixisstudio/snitch` — или релизный tarball. macOS: упакованное приложение или `brew`.

## Как появился Windows-порт

Я веду проект один. Windows-порт сделал не я — пользователи прислали баг-репорты с анализом первопричины, а незнакомец прислал три PR, починившие захват + правильный интерфейс + падение при старте. Open source работает как обещано. v1.0.5 вышла на прошлой неделе.
