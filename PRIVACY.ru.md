# Приватность

[English](PRIVACY.md) | [Français](PRIVACY.md) | [Español](PRIVACY.es.md) | [Deutsch](PRIVACY.de.md) | **Русский** | [日本語](PRIVACY.ja.md) | [Português](PRIVACY.pt-BR.md) | [中文](PRIVACY.zh-CN.md)

Snitch — инструмент приватности: он не должен сливать те самые данные,
которые помогает вам наблюдать.

**Телеметрия: отсутствует.** Ни аналитики, ни отчётов об ошибках, никаких
вызовов «домой».

**Исходящие сетевые вызовы Snitch: все опциональны, все выключены по
умолчанию.** Всё остальное — пассивное наблюдение или ваше действие:
тихого трафика нет:

- захват пакетов на ваших локальных интерфейсах (пассивное наблюдение),
- чтение системной таблицы ARP/соседей (без активного сканирования),
- обратный DNS через резолвер ОС — стандартные PTR-запросы, которые и так
  неявно происходят при любой сетевой активности (`SNITCH_DISABLE_PTR=1`
  отключает их полностью),
- веб-UI на `127.0.0.1` для вашего же браузера.

**Десктоп-приложение проверяет github.com на новые релизы** при запуске и
каждые 6 ч (electron-updater, читает публичные `latest-*.yml`). Это
единственный периодический исходящий вызов. Отключается в *Настройки →
Обновления → Проверять автоматически* (сохраняется) или через
`SNITCH_NO_UPDATE=1`. Docker-сборка и сам бэкенд никогда не проверяют.

**Загрузка базы GeoIP** (*Настройки → Геолокация*) скачивает ~50 МБ с
db-ip.com — только по вашему клику, с явным согласием.

**Threat intelligence (opt-in, выключено по умолчанию).** Когда вы
настраиваете провайдера (AbuseIPDB, AlienVault OTX или VirusTotal) *и*
вставляете свой API-ключ в настройках, Snitch спрашивает у провайдера
репутацию новых публичных хостов — отправляется только проверяемый IP.
Вердикты кэшируются локально; ключ хранится в `snitch.db` (не пишется в
логи, маскируется в UI). Без провайдера или ключа — ноль запросов:
`ti.check()` — холостой вызов.

**Внешние webhook'и (opt-in, выключены по умолчанию).** Когда вы вставляете
URL webhook'а (Discord, Slack, endpoint Telegram-бота или любой URL) и
включаете переключатель, тексты warning/critical-тревог отправляются
POST'ом на этот endpoint в реальном времени. При выключенном
переключателе ничего не отправляется.

**Локальное обогащение LLM (opt-in, выключено по умолчанию).** При
`slm_enabled` *метаданные* алертов (тип, процесс, назначение) могут
отправляться модели, совместимой с Ollama — **только loopback**: backend
отклоняет любой endpoint, не резолвящийся в 127.0.0.1 / ::1.
Детерминистические шаблоны остаются стандартом.

**Пакеты IOC никогда не передаются Snitch.** `GET /security/iocpack`
кодирует ваши индикаторы в фильтр Блума + randomized response (ε≈4,6)
и отдаёт файл — вы решаете, делиться ли им. Импорт возвращает лишь
вероятностные подсказки; автоблокировки нет.

**Зонды инспекции остаются read-only и локальными.** Зонд eBPF,
инспекция Frida, счётчики `perf_event_open`, проверки целостности
модулей и респондер sinkhole лишь *читают* локальное состояние и слушают
на 127.0.0.1 — никто не отправляет данные.

**Геолокация — только офлайн.** Как только `.mmdb` DB-IP Lite или MaxMind
GeoLite2 окажется в `<data_dir>/geo/`, запросы выполняются локально. Без
базы IP просто не показывают местоположение. HTTP-сервиса геолокации нет —
ip-api.com был удалён именно потому, что отправлял посещаемые IP третьей
стороне в открытом виде.

**Что хранится локально:**

| Данные | Место | Хранение |
|---|---|---|
| Поминутные агрегаты трафика | `snitch.db` | 24 ч (настраивается: `retention_hours`) |
| История тревог | `snitch.db` | то же окно |
| Настройки (фильтры, белый список, язык…) | `snitch.db` | до вашего изменения |
| API-токен | `api_token.txt` (0600) | пересоздаётся при запуске в Electron |
| Логи | `logs/snitch.log` (ротация) | макс. ~5 МБ |

Каталог данных: `data/` в dev/Docker, `%LOCALAPPDATA%\Snitch` в Windows,
`~/Library/Application Support/Snitch` в macOS, `~/.local/share/snitch` в
Linux при установленном запуске.

## Новое в v1.4 (приватность)

- **Блоклист по URL (opt-in)** — *локальный файл* читается чисто локально; *URL* — один ограниченный HTTPS-запрос (≤4 МиБ, ≤10 с), подтверждаемый в UI и помеченный `remote_fetch`.
- **Удалённое сопряжение (opt-in, выкл.)** — API слушает только 127.0.0.1; включение сохраняет `lan_bind` до следующего запуска — токен обязателен для каждого запроса.
- **Песочница без сети** — `POST /security/sandbox` запускает бинарник в namespace без сети (`unshare -n` Linux) или seatbelt (`sandbox-exec` macOS): нулевой egress, вывод остаётся на машине.
- **IOC `format=proof`** — засоленные листья SHA-256 + корень Merkle: точное членство без перечисления неподозреваемых индикаторов; ничего не передаётся автоматически.
- **Встроенная модель** — `slm_mode=embedded` загружает ваш `.gguf` в процесс через `llama-cpp-python` — ноль сети; Snitch никогда не скачивает веса.
