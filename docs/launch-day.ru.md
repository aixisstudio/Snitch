## Сработавшая последовательность

1. **Сначала конверсия**: мультиязычный README, чистый social preview, topics, Discussions — до любого поста.
2. **Один пик**: стек HN + Reddit + PH в один день; важна скорость, не недельный объём.
3. **Ответы <60 с**: мгновенный авторский комментарий на HN решил исход.
4. **Локальное масштабируется**: README zh-CN принёс ~55 китайских визитов/день после поста в CN-рассылке.
5. **Никакой холодной аудитории**: без подписчиков в X/LinkedIn постить бессмысленно — лучше вкладываться в существующие сообщества.
