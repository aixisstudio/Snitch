> **Цель: 100–300⭐ за 24 ч в день Д → попадание в GitHub Trending → самоподдерживающийся цикл.**
> Золотое правило: весь трафик должен сойтись на репо в ОДИН день. Каноническая версия со всеми таблицами — `growth-campaign.md` (EN/FR).

## Стратегия в 4 слоя

```
Слой 4 — ДЛИННЫЙ ХВОСТ (недели)    SEO-статьи, вечнозелёные Q&A, каталоги
Слой 3 — ЦИКЛ РЕКУРРЕНТНОСТИ       каждый релиз = новый повод шерить
Слой 2 — ДЕНЬ Д (вторник)          PH + репост HN + Reddit + соцсети, всё сразу
Слой 1 — КОНВЕРСИЯ (всегда вкл.)   репо, конвертирующий посетителя в звезду
```

## Слой 1 — Конверсия репозитория

Анонимизированный social preview, включённые Discussions + закреп, 20/20 topics, FUNDING.yml, README на 8 языках + демо-GIF, ненавязчивый star-CTA, awesome-бейдж, прямые ссылки на скачивание по ОС в первых строках.

## Слой 3 — Рекуррентность

- Каждый релиз = повод постить (v1.x → новая волна каждые 2-3 недели)
- Changelog → кросспост dev.to/Medium
- Ежемесячный пост « State of Snitch » с реальными метриками

## Слой 4 — Длинный хвост

- SEO-статьи из `docs/articles/` (альтернативы GlassWire/Little Snitch) на dev.to/Medium
- Ответы StackExchange/Quora « how to see what my PC connects to »
- Каталоги: AlternativeTo, SaaSHub, LibHunt, awesome-списки
- Локализованные сообщества: Qiita/Zenn (JP), V2EX/Juejin (CN), dev.to ES/PT
